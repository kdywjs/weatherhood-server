# 지역별 날씨 데이터 테스트 시나리오

최초작성일: 2026-11-02
마지막 수정일: 2026-11-02

합성 기상청 응답과 고정 시계를 사용한다. 인증키를 사용한 실제 제공 범위 검증과 구분한다.

| 테스트 ID | 기능 | 테스트 조건 | 입력값 | 기대효과 |
| --- | --- | --- | --- | --- |
| WTH-001 | 격자 변환 | 기상청 표준 서울 좌표와 잘못된 좌표 | 37.5665/126.978, NaN/Infinity/범위 밖 | 서울 60/127, 잘못된 값은 INVALID_REQUEST |
| WTH-002 | 지원 위치 | 공식 목록에 없는 위치 | 서울, 도쿄, 남해 일부 미등록 격자 | 목록 기반 허용·거부, 사각형 범위로 국내 추정 안 함 |
| WTH-003 | 발표 선택 | 자정·월 경계와 제공 지연 | 00:05/00:10, 00:44/00:45, 02:09/02:10 | 이전 일자 또는 새 발표 시각을 올바르게 선택 |
| WTH-004 | 응답 검증 | HTTP 성공의 본문 오류·빈 응답·잘못된 격자 | 기상청 오류/0건/다른 nx | 정상 자료로 저장하지 않으며 키 미노출 |
| WTH-005 | 코드 변환 | 실황 하늘상태 없음·알 수 없는 코드·결측 수치 | SKY 없음, PTY 6/99, -999, NaN | 맑음·0을 만들지 않고 null과 원본 자료별 코드 의미 유지 |
| WTH-006 | 강수량 | 미만·범위·강수 없음·정성 코드 | 1mm 미만, 30~50mm, 0, 연장 구간 2* | 수치·범위·기간 보존, 정성 코드를 mm/m/s로 변환하지 않음 |
| WTH-007 | 출처 조합 | 같은 시각의 실황과 예보 | 실황 기온 + 예보 하늘상태 | 값별 출처·발표/관측 시각 보존, source=mixed |
| WTH-008 | 과거 자료 | 대상 시각 이후 발표 예보·미래 실황 | 09시 대상 14시 발표, 현재 이후 관측 | 당시 자료로 소급 적용하지 않음 |
| WTH-009 | 결측 구간 | 중간 1시간 자료 없음 | 00시/02시 점 | 01~02시를 누락으로 표시하고 직전 값 연장 안 함 |
| WTH-010 | 현재 요약 | 아직 새 실황이 제공되지 않은 정시 직후 | 15:05 현재, 14시 실황·15시 예보 | 최신 제공 실황 14시 기온을 현재 요약에 우선 사용 |
| WTH-011 | 오래된 예보 | 허용 시간보다 오래된 미래 예보 | 이전 발표, 허용 0/2시간 | 기본 미제공, 허용 시 stale, 한도 초과 시 배제 |
| WTH-012 | 중복 수집 | 같은 격자 동시 조회 | 여러 동시 refresh | 같은 자료 키는 한 번 수집·저장 |
| WTH-013 | 수집 실패 | 저장 자료가 있고 재조회 실패 | 실패하는 gateway | 정상 저장본 유지, 재시도 간격 동안 반복 호출 안 함 |
| WTH-014 | 저장과 보존 | 재시작·48시간 전 자료·미래 예보 | 파일 H2 다시 열기, 과거/미래 대상 | 저장 복구, 아직 유효한 미래 자료 삭제 안 함 |
| WTH-015 | 페이지 검증 | 2페이지 응답 및 후속 페이지 실패 | totalCount 2, page별 1개 | 전부 수집 후 저장, 일부 실패는 저장 안 함 |
| WTH-016 | 호출 예산 | 동시 예약·실패·재시작 | 작은 일일 호출/용량 예산 | 원자적 제한, 예산이 재시작으로 초기화되지 않음 |
| WTH-017 | HTTP 계약 | 정상·입력 오류·위치/날짜 미지원·자료 없음 | 두 조회 API | JSON 계약과 200/400/422/503, Retry-After 일치 |
| WTH-018 | 초기 기동 | 오후에 비어 있는 DB로 오늘 조회 | 15:12 고정 시계, 합성 실황·예보 | 00시부터 자료 수집·반환, 두 번째 조회 재호출 없음 |
| WTH-019 | 비밀값 | 외부 HTTP 실패와 입력 오류 | 테스트용 authKey | 응답·예외에 키나 공급처 URL 미노출 |
| WTH-020 | 요약 기간 | 다음 24시간과 날짜별 최고/최저 없음 | 여러 날짜의 점 자료 | 시간별 데이터로 하루 극값·대표 날씨를 임의 산출하지 않음 |
| WTH-021 | 외부 응답 한계 | 큰 응답과 헤더 이후 본문 지연 | 2MiB 초과 본문, 본문 지연 | 전체 응답 시간·크기 제한 적용, 실패 원문·키 미노출 |

실제 인증 조회는 별도 수용 검증이다. 공식 제공 지연·소급 조회·연장 구간·중기예보·실기기는 이 자동 검증만으로 통과 처리하지 않는다.
